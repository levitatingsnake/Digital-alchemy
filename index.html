00 / PROJECT PROMETHEUS

Self-adversarial discovery: test saved rules on a separate, reproducible holdout set and search for counterexamples.

Prometheus will compare each saved rule against a held-out set of 128 synthetic states, identify its worst counterexample, and report whether its performance generalises beyond the original sample generator. No current state will be changed.
Map the model’s weak regions by testing saved rules against targeted synthetic state families.
Probe weak regions with targeted local search to seek worse counterexamples than random sampling found.

00C / ANOMALY LAB

Construct controlled challenge protocols from the model’s weakest regions. Compare targeted states with a broad synthetic control set.

The lab will identify a difficult region, generate a repeatable challenge set, and compare saved rules against a separate control sample.

00F / DISCOVERY CYCLE

Run the connected analysis sequence: map conditional patterns, design discriminating probes, then stress-test the saved rules. Preserves the current state and rule library.

The cycle links discovery, experiment design, and adversarial challenge into one repeatable pass.

00E / EXPERIMENT DESIGNER

Find synthetic states where competing saved rules make sharply different predictions, then rank the most informative probes.

The designer will search for test states where saved rules disagree most, making them useful probes for distinguishing candidate explanations.

00D / PATTERN VAULT

Search for conditional behaviour in saved rules, then test the strongest pattern on an independent synthetic sample.

The scanner will formulate conditional hypotheses from one sample and attempt to replicate them on a separate sample.

00A / THE LAW FORGE

Evolve the discovery method itself. Competing search strategies generate candidate rules, learn from held-out performance, and mutate their search settings across three generations.

The Law Forge will compare six discovery strategies over three generations. It changes no current state and saves its report with your experiment data.
